## Modèles courts

### Email stakeholders

```
Objet : [Décision] — [Produit/Projet]

Bonjour,

Nous avons décidé de [DÉCISION].

Contexte : [2–3 phrases + données clés]

Impacts : [liste courte]

Prochaines étapes :
- [Action 1] — [owner] — [date]

Questions : [contact]

Cordialement,
[Signature]
```

### Message Slack / Teams

```
📌 Décision : [résumé une ligne]
Pourquoi : [lien doc / 1 phrase]
Impact : [équipes concernées]
Next : [1–2 actions + dates]
```

## Prompt IA

```
J'ai décidé de [DÉCISION] pour les raisons suivantes : [RAISONS].
Cela impacte [ÉQUIPE/PROJET].

Rédige un email pour les stakeholders qui :
1. Annonce la décision clairement
2. Explique le pourquoi (données à l'appui)
3. Rassure sur les impacts négatifs
4. Donne les prochaines étapes

Ton : professionnel mais empathique.
Public : [direction / équipe / clients internes]
```
